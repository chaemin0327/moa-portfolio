## 결정

1. `인턴/경력`을 기본 분류로 추가합니다. 회사·부서, 직무·역할, 근무 기간, 담당 업무, 성과, 기술, 관련 링크를 기존 경험 필드에 기록합니다.
2. 프로젝트·공모전·수상·자격증·논문·해외 경험·동아리/대외활동·교육/기타를 유지합니다. 기존 기록의 의미를 임의로 바꾸지 않습니다.
3. 분류 선택 마지막에 `＋ 직접 추가`를 둡니다. 봉사활동, 멘토링, 창업, 강연, 어학 시험처럼 기본 분류가 맞지 않으면 최대 30자의 이름을 입력합니다.
4. 직접 만든 분류는 별도 관리 화면을 요구하지 않습니다. 경험에 이름을 저장하고, 기록이 존재하는 이름만 필터·타임라인 선택에 노출합니다. 다음 기록에서는 기존 이름을 재사용할 수 있습니다.
5. 태그는 Java·협업 등 세부 역량, 분류는 경험의 성격을 나타냅니다. 모든 세부 역량을 새 분류로 만들지 않도록 입력 예시를 제공합니다.
6. 입력창을 줄이기 위해 기존 필드를 재사용하며 임의의 입력 항목을 설계하는 기능은 이번 범위에 포함하지 않습니다.

## API 계약

- 기존 종류는 그대로 유지하고 `WORK`, `CUSTOM`을 추가합니다.
- `customCategory`: 최대 30자 문자열. `CUSTOM`일 때만 이름이 필수이며, 앞뒤 공백과 연속 공백을 정리해 저장합니다.
- 기존 요청에서 `customCategory`가 없어도 기존 종류는 정상 처리합니다.
- `CUSTOM`에서 기본 종류로 수정하면 사용자 지정 이름은 비웁니다.
- 카드·상세·검색·필터·타임라인·포트폴리오 모두 같은 이름을 사용합니다.
