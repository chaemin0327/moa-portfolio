## 협업 규칙 도입 후

작업 타입과 영역 라벨이 있는 [이슈](https://github.com/chaemin0327/moa-portfolio/issues)로 시작하고, [PR](https://github.com/chaemin0327/moa-portfolio/pulls?q=is%3Apr)에서 변경 이유·검증·연결 이슈를 확인합니다.

- BE: Java API, 데이터 저장, 서버 검증 및 테스트
- FE: 경험 입력, 필터, 타임라인, 포트폴리오와 화면 디자인
- COMMON: 협업 문서, 템플릿, 빌드와 CI
